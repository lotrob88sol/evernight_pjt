# EVERNIGHT

Mobile-first interactive prototype for the EVERNIGHT indie horror game project.

## Prototype v0.1
- Choose to enter as yourself or Han Yujin
- Explore Moon Market, Gardens, Old City and Solar District
- Read character Moments and profiles
- Existing-character mode reveals private information
- Advance time until the 05:47 anomaly

Open `index.html` directly or deploy the repository with GitHub Pages.
